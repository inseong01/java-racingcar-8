# java-racingcar-precourse

## 문제 정리

사용자는 자동차의 이름과 대수, 시도 횟수를 설정할 수 있다.

주어진 횟수 동안 자동차는 전진하거나 멈춘다.

자동자의 전진 조건은 무작위 값이 4 이상이어야 한다.

우승자는 한 명 이상일 수 있다.

사용자가 잘못된 문자열을 입력하면 메시지가 전달되는 동시에 오류가 발생해 프로그램을 종료시킨다.

## 개발

### 애플리케이션 흐름

**성공**

```
1. 사용자는 자동차 이름을 작성한다. (, 구분)
2. 자동차 이름을 검증한다.
3. 자동차를 생성한다.
4. 사용자는 시도할 횟수를 입력한다.
5. 시도 횟수를 검증한다.
6. 시합을 생성한다.
7. 시합의 기본 조건(자동차, 라운드 횟수)을 설정한다.
8. 시합을 실행한다.
9. 결과 형식을 출력한다.
```

**예외**

이름 잘못 입력한 경우

```
1. 사용자는 시합할 자동차 이름을 잘못 작성한다.
2. 자동차 이름을 검증한다.
3. 메시지를 출력하고 오류를 던지는 동시에 프로그램은 종료된다.
```

횟수 잘못 입력한 경우

```
1. 사용자는 시합할 자동차 이름을 작성한다.
2. 자동차 이름을 검증한다.
3. 사용자는 시도할 횟수를 잘못 입력한다.
4. 시도 횟수를 검증한다.
5. 메시지를 출력하고 오류를 던지는 동시에 프로그램은 종료된다.
```

### 구현 기능 목록

**입력**

`자동차 이름 입력`

`시도 횟수 입력`

**출력**

`자동차 이동 거리 출력`

`우승 자동차 이름 출력`

**검증**

`자동차 이름 검증`

`시도 횟수 검증`

**자동차**

`이름 설정`

`이동범위`

`이동하기`

**시합**

`참가 자동차 설정`

`라운드 횟수 설정`

`라운드 실행`

`우승자 판별`

**라운드**

`주사위 생성`

`자동자 이동`


### 예외 조건

예외조건은 계속 추가한다.

**자동차 이름 검증**

1. 입력하지 않은 경우

2. 5자 이하가 아닌 경우

3. 중복된 이름이 있는 경우

**시도 횟수 검증**

1. 입력하지 않은 경우

2. 글자가 포함되어 있는 경우

3. 숫자가 0인 경우

4. 숫자가 음수인 경우

5. NaN인 경우
